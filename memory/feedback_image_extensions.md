Always use `.png` as the file extension for all image references in this project's HTML. Never use `.jpg` or `.jpeg`.

**Why:** The user corrected this explicitly — all images in the workshop are saved as PNG files.

**How to apply:** Whenever adding or editing `<img src="images/...">` tags in index.html (or any other HTML file in this project), always write the extension as `.png`.
